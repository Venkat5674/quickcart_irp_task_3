Part A Theoretical Answers

Q1: Why add displayProduct() to the prototype instead of the constructor?
Adding methods to the prototype ensures all instances share one single copy in memory via the prototype chain (__proto__), saving memory compared to creating a new closure per instance inside the constructor.
Q2: What is the difference between __proto__ and prototype?
prototype is a property of constructor functions and classes used to initialize new objects. __proto__ is the accessor property on object instances pointing to their actual prototype.
Q3: What happens when JavaScript cannot find a property on an object?
JavaScript ascends the prototype chain until it reaches Object.prototype.__proto__ which is null. If not found, it returns undefined.

Part B Key Conceptual Insights

Q: What is the difference between Object.freeze() and Object.seal()?
Object.seal() blocks adding or deleting properties, but existing writable properties can still be changed. Object.freeze() blocks additions, deletions, AND makes all properties read-only.
Q: How is Map different from a plain Object?
Map keys can be of any type (including objects and functions), guarantees insertion order iteration, has a direct .size property, and prevents prototype pollution.
